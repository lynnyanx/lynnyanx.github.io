# 工业物联网云监控系统

## 项目概述
基于 Grafana 构建的云端工业物联网 (IIoT) 监控与可视化系统。

*注：因涉及保密数据，暂不提供视频演示，系统效果请参考 `/Image` 目录中的截图。*

## 核心功能
- 工业物联网设备实时监控与数据可视化
- 设备状态追踪与统计分析
- 交互式仪表盘与设备地图界面
- 基于爬虫的自动化数据采集
- 面向工业数据处理的自研算法

## 技术栈

**后端：**
- Flask（主框架）
- Django（辅助框架）
- RESTful API 设计
- 基于 Python 的算法与测试软件

**前端：**
- Vue.js
- Element UI
- JavaScript、HTML、CSS

**数据库：**
- MySQL
- PostgreSQL
- Redis

**运维与工具：**
- Linux
- Docker
- Supervisor
- Kubernetes（基础应用）
- Postman / Apifox（API 测试）

## 系统架构
前后端分离架构，通过 RESTful API 通信。
